# LLM-project
group project cclark
Smart Ai recipe agent

## requirements
python
ollama
model = llama3.2

## how to run
run below script within project terminal
python./main.py

Ollama must be running. On Windows the Ollama desktop service usually starts with the app, otherwise run "ollama serve" in another terminal.

## Example prompts
1. I have eggs, rice, onion and oil. Find a recipe, check missing ingredients, calculate calories and save it.
2. I have oats, banana and milk. Suggest something below 450 calories and explain how to cook it.
3. For the recipe you just suggested, how much protein per serving? Save it with the note "breakfast".
